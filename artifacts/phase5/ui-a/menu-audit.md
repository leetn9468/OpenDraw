# U3-A command reachability audit

The retired 27-item text strip has no exclusive commands. Native menus retain every prior toolbar action; shell-native destinations are listed where a command moved.

| Prior command | Reachable from |
|---|---|
| New, Open, Save, Export | File menu and native toolbar |
| Undo, Redo | Edit menu |
| Select, Direct Select, Pen, Rectangle, Ellipse, Text, Image | Tools menu and tool rail |
| Style | Object menu |
| Properties | Object menu; reveals Inspector |
| Zoom Out, Actual Size, Zoom In | View menu; out/readout/in toolbar cluster |
| Zoom Fit | View menu and native toolbar |
| Align Left | Object menu and Inspector |
| Group, Ungroup, Make Compound, Release Compound | Object menu and Inspector |
| Layers | View menu and native toolbar toggle |
| Gradient | Object menu and Inspector popover |
| Snap | View menu |

The new Inspector panel toggle is available from View and the toolbar. Open continues to accept both native and SVG documents, and the File menu names the SVG route explicitly as “Import SVG…”.
