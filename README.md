# AI10 Clean-Room Vector Editor

This repository contains an original, clean-room vector-editor project. The name
`AI10` is a working project label, not a compatibility claim or product name.

Phase 1 defines the product, Phase 2 the foundation, Phase 3 a core editing slice,
and Phase 4 a selected capability expansion. No legacy decompiler output belongs here.

## Current status

- Phase: 4 — Selected Capability Expansion and Compatibility Layers
- Product posture: open-source learning project with a usable personal-tool MVP
- Platform: macOS 13 or newer, Apple Silicon and Intel
- Planned foundation: Swift 6, AppKit, Core Graphics, Core Text, Swift Package
  Manager, Swift Testing
- Compatibility: SVG 1.1 subset for interchange; original native format planned

Phase reviews: [Phase 1](docs/phase-1/README.md), [Phase 2](docs/phase-2/README.md),
[Phase 3](docs/phase-3/README.md), and [Phase 4](docs/phase-4/README.md).
